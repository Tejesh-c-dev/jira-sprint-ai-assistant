# DATA-11 synthetic fixtures

Every CSV in this directory is a small, deterministic synthetic fixture created for DATA-11.
The records, identifiers, names, and text are invented for tests and are not copied, reconstructed,
trimmed, or derived from the upstream Spring XD data. These files must not be presented as original
Spring XD records.

The set intentionally covers quoted commas, multiline text, omitted optional values, one issue
linked to multiple sprints, a duplicate sprint/issue link pair, an unknown issue reference, and an
unknown sprint reference.
